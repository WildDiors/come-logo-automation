# COME联运logo自动化

团队共享的 Codex Logo 生成 Skill。

## 包含的 Skill

### `come-logo-automation`

根据内置参考图生成黑底彩虹书写体英文或数字 Logo，并通过明确的结构确认节点控制上色：

1. 点击技能后只需在提示词末尾输入 Logo 名称，默认一次生成 4 张独立的纯黑底、纯白字形结构稿；也可指定 5 张或 6 张。
2. 选择一个方案只会将其设为底稿，不会自动上色。可以继续修改、组合方案、锁定局部，或重新探索方向。
3. 黑白结构稿可以反复修改，没有固定次数限制；未提及的字形、字距和构图应保持不变。
4. 明确回复“结构确认”后锁定结构，再回复“默认上色”或指定配色、材质和背景进行渲染。

所有阶段默认保持纯黑背景。只有明确提出修改背景时，才会采用渐变或其他彩色背景。

英文名称固定采用“首个英文字母大写，其余英文字母小写”的设计形式，与输入大小写无关。例如 `drem`、`DREM`、`dReM` 都生成 `Drem`，`AXC9` 生成 `Axc9`。数字保持不变；数字开头时，第一个英文字母大写（`9ABC` → `9Abc`）。此规则贯穿黑白探索、修改、结构确认和上色。

技能没有默认 Logo 名称；参考图中的 `Come` 只用于展示风格，不会作为生成内容。

## 在 Codex 中使用

克隆本仓库，并在仓库目录中打开 Codex。Codex 会自动扫描：

```text
.agents/skills/come-logo-automation/
```

调用示例：

```text
$come-logo-automation M3
```

或点击技能后，在自动出现的短提示后直接输入：

```text
AXC9
```

选择底稿后可以直接描述修改：

```text
选 B，只缩短尾划，其他部分保持不变
```

结构满意后依次输入：

```text
结构确认
默认上色
```

如果 Skill 没有立即出现，请刷新技能列表，并使用 `/skills` 检查。

## 安装为个人 Skill

如果希望在其他所有仓库中使用，可将完整目录复制到：

```text
$HOME/.agents/skills/come-logo-automation/
```

请保留 `SKILL.md`、`agents/`、`assets/` 和 `references/` 的目录结构。
